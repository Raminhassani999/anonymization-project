# Dataset Description

## Dataset Name

Diabetology Synthetic Dataset

## Format

Excel (.xlsx)

## Purpose

Synthetic medical dataset used for testing anonymization approaches.

## Structure

Main sheet:
- DM
- 1337 rows
- 103 columns

Each row represents one patient visit.

## Sensitive Information Types

Direct identifiers:
- First Name
- Surname
- Patient Code
- Tax Code

Potential quasi-identifiers:
- Birth Date
- Age
- Sex
- Assessment Date

Sensitive medical information:
- Diabetes diagnosis
- Laboratory results
- Treatments
- Complications

## Privacy

The dataset is fully synthetic and contains no real personal data.
